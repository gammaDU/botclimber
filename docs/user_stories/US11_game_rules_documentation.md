### US11: Game Rules and Physics Documentation
**As a** Player,
**I want** clear documentation of the game's physics and rules,
**So that** I can accurately calculate my bot's movement and optimize its climbing strategy.

**Acceptance Criteria:**
- The system provides a public rules and physics reference: [game_rules.md](../game_rules.md).
- The game engine's implementation matches the documented constants to ensure bot predictability.
