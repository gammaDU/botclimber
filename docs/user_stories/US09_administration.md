### US09: Server Administration and Monitoring
**As an** Administrator,
**I want** to monitor the server status and manage player accounts,
**So that** I can ensure system stability and maintain the integrity of the game.

**Acceptance Criteria:**
- The system provides a way to view server health metrics (e.g., CPU usage, memory, active connections).
- The administrator can view a list of all registered users and their status.
- The administrator can disable or delete a player account if necessary.
- The administrator has the ability to reset or prune the high score leaderboard.
- The administrator can monitor the current number of active bots and their performance impact.
- The administrator can change the active game mode of the server via the Admin API (Checkpoint vs. Hardcore).
- The administrator can trigger a regeneration of the game world (procedural seed update).
- The administrator can reset the position and state of a specific player by their ID.
- The administrator can reset the position and state of all active players simultaneously.
