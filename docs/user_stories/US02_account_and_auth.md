### US02: Account Management
**As a** Player,
**I want** to register and manage my account details via the web frontend,
**So that** I can personalize my presence and generate credentials for my bot.

**Acceptance Criteria:**
- The web frontend (US06) provides a user-friendly interface for registration, login, and profile management.
- The system allows creating a new account with a unique username and a password.
- The system allows users to authenticate (Login) and receive a secure session token (JWT).
- A logged-in user can change their display name.
- A logged-in user can generate or regenerate their unique API key.
- API keys must be kept secure and not exposed to other players.
