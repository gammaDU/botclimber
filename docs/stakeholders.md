# Stakeholders: Botclimber

This document identifies the key stakeholders involved in the Botclimber project.

### 1. Players (Primary Users)
- **Description**: Individuals or teams who write code (bots) to play the game.
- **Interests**: Reliable API, fair competition, low latency, clear documentation, and accurate leaderboards.
- **Responsibility**: Developing and maintaining their own client-side bot logic.

### 2. Administrator
- **Description**: The entity responsible for running the Botclimber server.
- **Interests**: System stability, security (preventing unauthorized access), resource management, and maintaining the integrity of high scores.
- **Responsibility**: Server hosting, monitoring, and potentially managing API keys.

### 3. Development Team
- **Description**: The software engineers and architects building the Botclimber server and game logic.
- **Interests**: Code maintainability, scalability, performance (Rust efficiency), and feature implementation.
- **Responsibility**: Implementing the REST API, game physics, state management, and persistence layer.

### 4. Spectators
- **Description**: Users interested in the results of the competitions and the high-score rankings.
- **Interests**: Visibility of scores, transparency in rankings, and potentially watching bot performances (if a frontend exists).
- **Responsibility**: Engaging with the leaderboard and community.
